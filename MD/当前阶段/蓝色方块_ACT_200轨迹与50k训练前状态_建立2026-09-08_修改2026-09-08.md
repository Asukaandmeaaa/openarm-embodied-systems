```bash
cd /home/lushilin/openarm_vla_ws
conda activate vla

export PYTHONPATH="$PWD:$PWD/official/openarm_dataset/src:$PWD/official/openarm_mujoco/src"
export CUDA_VISIBLE_DEVICES=0

PROMPT="Pick up the blue cube, hold it for 2 seconds, place it nearby, and return the right arm home." \
STEPS=50000 \
BATCH_SIZE=8 \
NUM_WORKERS=4 \
MIN_EPISODES=160 \
EVAL_SPLIT=0.0 \
EVAL_STEPS=0 \
SKIP_VALIDATION=1 \
OPENARM_TRAIN_LOG=results/act_training/act_openarm_cube_pick_blue_200_50k_20260908.log \
scripts/train_act_openarm.sh \
  data/lerobot/openarm_cube_pick_expert_blue_200_train160_20260908 \
  outputs/act_openarm_cube_pick_blue_200_50k_20260908
```

配置：ACT、batch 8、50k steps、每5k保存、STATE=IDENTITY、ACTION/VISUAL=MEAN_STD。
`EVAL_SPLIT=0.0` 保证160条全部训练，40条holdout完全隔离，因此本轮不产生离线
`eval_loss`。checkpoint 选择以未见 seed 的完整闭环成功率为准。

## 6. 初步抓取保持结果与下一门禁

旧验证器在中央 `X/Y ±0.02 m` 范围只验证抓取、抬升和保持，50k结果为
`26/30=86.7%`；旧20k同口径为 `13/30=43.3%`。二者不是完整任务成功率。

完整范围 `X±0.05 m / Y±0.06 m` 的30个全新seed结果为：抓取保持27、松爪27、
稳定放置26，因此物体任务成功 `26/30=86.7%`。右臂学习式回位为 `0/26`。

成功口径分为两层：`task_success` 表示抓取、保持、放置和松爪完成；
`full_sequence_success` 另外要求右臂回位。回位是任务后的复位/安全指标，不再否定已经
完成的物体操作；验证器仍继续运行并报告该指标。
