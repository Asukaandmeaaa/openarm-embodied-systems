# 蓝色方块固定黑盒任务：ACT 200轨迹、50k训练与30-seed闭环

- 建立日期：2026-09-11
- 修改日期：2026-09-11
- 状态：专家数据、严格回放、固定切分、LeRobot转换、ACT 50k训练和30个未见seed闭环均已完成
- 当前结果：真实落盒并回位 `27/30 = 90.0%`

## 1. 当前结论

固定黑盒任务已经形成完整闭环：

```text
随机蓝色方块（X±0.05 m / Y±0.04 m / yaw±15°）
→ 右臂抓取
→ 抬升至少5 cm并连续保持2 s
→ 搬运到固定黑盒
→ 松爪
→ 方块在盒内稳定至少0.5 s
→ 右臂回位，左臂保持停放状态
```

结果汇总：

```text
216次专家尝试
→ 200条在线成功（92.59%）
→ 严格actuator replay 200/200
→ 固定切分160 train / 40 holdout
→ LeRobot v3训练集185,890帧
→ ACT训练50,000 steps
→ 30个完全未见seed：27/30真实落盒并回位（90.0%）
```

这不是旧的“搬运到附近随机位置”任务。黑盒任务的 `task_success` 必须要求方块最终位于
固定黑盒安全范围内并稳定，不能用“移动了一定距离”代替落盒。

## 2. 专家规划与成功门禁

专家使用离散抓取候选加MuJoCo完整前向预演：

```text
生成抓取yaw候选
→ IK和碰撞快速过滤
→ 对候选执行无录制完整物理rollout
→ 验证双指接触、抬升、保持、运输、落盒、松爪、回位和静态尾段
→ 第一个完整成功候选重新reset相同seed
→ 正式录制
```

关键修复：

- 候选不再只按抓取阶段或终点IK评分；
- candidate失败后会自动预演下一个可达分支；
- 预抓取高度由7 cm提高到9 cm，避免关节插值路径提前推动边缘方块；
- 抓取前方块位移超过5 mm直接拒绝；
- `release_above_box` 不再绕过最终盒内判断；
- 静态尾段继续驱动关节收敛到home，提高30 Hz严格回放余量；
- strict replay会把黑盒移动到正式位置，并输出 `inside_black_box`。

## 7. 当前判断与下一步

当前50k模型已经证明固定黑盒任务具备较强的未见位姿泛化能力：严格真实落盒并回位
`27/30=90.0%`。相较旧附近放置50k基线的 `26/30=86.7%`，数字略高，但两个任务的目标
几何和成功合同不同，只能作为工程参考，不能视为同口径模型排名。

下一步优先级：

1. 使用相同 `20273000..20273029` 比较40k、45k和50k checkpoint，按真实落盒率选模型；
2. 用viewer复核失败seed `20273003`、`20273019`、`20273027`；
3. 再用至少100个全新seed压测所选checkpoint，并按初始X/Y/yaw分桶；
4. 若要继续提高成功率，优先补充右侧边缘和较大正yaw附近的数据，而不是单纯增加训练步数；
5. 冻结最终checkpoint、验证器、seed清单、汇总报告和SHA256后，再作为后续π0/π0.5基线。

## 8. 禁止混用的口径

- 旧任务：把蓝色方块搬运到附近随机目标；范围为 `X±0.05 / Y±0.06 m`。
- 新任务：把蓝色方块放入固定中间黑盒；范围为 `X±0.05 / Y±0.04 m`。
- 新任务 `task_success` 要求方块实际在黑盒内稳定至少0.5 s。
- `full_sequence_success` 另外要求回位；本轮27条task success全部完成回位。
- 专家online success、strict replay valid、LeRobot episode数和策略闭环成功率是四个不同指标。
- 不允许用训练loss或“方块移动距离”替代真实盒内闭环判定。
