## 2. 任务流程

```text
RESET/STABILIZE
→ PLAN
→ MOVE_PREGRASP
→ APPROACH
→ CLOSE
→ VERIFY_GRASP
→ LIFT
→ HOLD（2 s）
→ TRANSPORT
→ PLACE
→ RELEASE
→ RETREAT
→ RETURN_HOME
→ SUCCESS
```

运动 waypoint 采用连续流式执行；只有 LIFT 后的 HOLD 保留完整 2 秒稳定窗口。
方块起始 XY、yaw 和附近放置目标随机化，左臂保持安全姿态。

## 5. ACT 20k 训练

训练入口：

```bash
PROMPT="Pick up the blue cube, hold it for 2 seconds, place it nearby, and return the right arm home." \
STEPS=20000 BATCH_SIZE=8 \
scripts/train_act_openarm.sh \
  data/lerobot/openarm_cube_pick_expert_blue_100_train80 \
  outputs/act_openarm_cube_pick_blue_100_20k
```

关键配置：

- policy：ACT；
- chunk_size / n_action_steps：100 / 100；
- batch size：8；
- workers：4；
- learning rate：`1e-5`；
- normalization：VISUAL=MEAN_STD、STATE=IDENTITY、ACTION=MEAN_STD；
- image transforms：关闭；
- eval interval：1000 steps；
- checkpoint interval：5000 steps；
- seed：1000。
